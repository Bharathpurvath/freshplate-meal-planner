# FreshPlate — Pantry & Meal Planner

FreshPlate is a responsive kitchen companion for using ingredients already at home, keeping an eye on best-before dates, planning simple meals, and building a grocery list.

## What it does

- Start with a small sample pantry and replace it with your own ingredients
- Track quantities, categories, and best-before dates
- See ingredients that may need attention soon
- Find recipe ideas ranked by pantry matches
- View ingredient lists and simple cooking steps
- Plan one meal for each day of the current week
- Add missing recipe ingredients to a categorized grocery list
- Check off groceries as you shop
- Save kitchen data in browser local storage on this device

## Run it

Open index.html in a modern browser. No installation, account, server, API key, or build step is required.

## Files

- index.html — page structure and copy
- styles.css — responsive visual design
- app.js — pantry, recipe matching, meal planning, and shopping-list behavior
- favicon.svg — FreshPlate icon

## Privacy

Pantry items, meal plans, and grocery lists stay in this browser's local storage. They are not sent to a server. Clearing this browser's site data removes them.

## Notes

FreshPlate is a planning tool. It does not determine whether food is safe to eat. Follow the package label and your local food-safety guidance.
